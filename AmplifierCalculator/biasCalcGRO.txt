## 1) Numeric results (example values already used)

Given (repeating so the numbers below are clear):

* (V_{CC}=12\ \text{V})
* (\beta = 200)
* (R_C = 680,\Omega)
* (R_E = 68,\Omega)
* (V_{RE}=1.20\ \text{V}) → (I_E = 1.2/68 = 0.0176470588\ \text{A})
* (V_{BE}=0.7\ \text{V})
* (R_2=680,\Omega)
* Computed earlier: (R_1 = 3504.615384615385\ \Omega)

### a) small-signal emitter intrinsic resistance (r_e)

Use thermal voltage ≈ 26 mV:
[
r_e = \frac{26\ \text{mV}}{I_E} = \frac{0.026}{0.0176470588}=1.4733\ \Omega
]

### b) (r_{\pi})

[
r_{\pi} = \beta \cdot r_e = 200 \times 1.4733 = 294.67\ \Omega
]

### c) Input impedance looking into the base (Zin at base)

For emitter un-bypassed:
[
Z_{in(base)} \approx r_{\pi} + (\beta+1)R_E
=294.67 + 201\times68 = 13,962.67\ \Omega \approx 13.96\ \text{k}\Omega
]

### d) Input impedance seen by a source connected to R1 (i.e. R1‖R2‖Zin_base)

First R1‖R2 = 3504.615‖680 = 569.5 Ω (exact).
Then Rin_source = parallel(569.5, 13,962.67) = **≈ 547.18 Ω**

So:

* (Z_{in(base)} \approx 13.96\ \text{k}\Omega)
* (Z_{in(source)} \approx 547.18\ \Omega)

(Interpretation: the low R2 and R1 values heavily load the base; the source sees ≈550 Ω.)

### e) Small-signal voltage gain (magnitude and dB)

Using small-signal formula with emitter degeneration:
[
g_m \approx \frac{1}{r_e} = \frac{1}{1.4733} = 0.6787\ \text{S}
]
[
A_v \approx -\frac{g_m R_C}{1 + g_m R_E}
= -\frac{0.6787 \times 680}{1 + 0.6787\times68}
\approx -9.788
]
Magnitude = 9.788 → in dB:
[
20\log_{10}(9.788) \approx 19.81\ \text{dB}
]

So **voltage gain ≈ −9.79 (≈ 19.81 dB magnitude)**. (Negative sign = 180° phase inversion.)

**Important practical note:** earlier we found (V_{CE}) calculated negative (transistor would saturate). The linear gain formula above assumes the transistor is in the active region; if the device is saturated the actual gain will be much lower. Use these small-signal results only while the transistor stays in the active region.
